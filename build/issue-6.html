🔭 2. graphify
命令行要 API Ke本地跑
Graphify-Labs/graphify
把代码、文档、PDF 全塞进去，变成一张能问的知识图谱
你电脑里散落的代码、说明书、PDF、截图，它一次读进来，理清谁引用谁、谁依赖谁，画成一张关系图。在 Claude Code 里敲 /graphify，它自己翻文件建图，之后你提问只查图不重读原文。得装 Claude Code 和 Python 3.10+，命令行操作，不是点开就能用的网页。
原文：Turn any codebase, with its docs, SQL schemas, configs, and PDFs, into a queryable knowledge graph. A /graphify skill for Claude Code, Cursor, Codex, and Gemini CLI: local deterministic AST parsing, every edge explained, no vector store.
为啥值得看
· 涨星每天六百多，说明被原始文件淹没的人真不少
· 和向量库方案不同，它每条边都给出来源，猜的和查到的分得清
· Karpathy 那种 /raw 杂物堆的痛点，正好是它瞄准的场景
上手难度
装个 Python 环境就能跑
